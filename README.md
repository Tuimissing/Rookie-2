# 🏨 Chef's Hotel Webpage

A beginner-friendly hotel landing page project built with HTML and CSS. This webpage showcases a fictional luxury hotel called "Chef's Hotel" and includes a warm, modern design with a polished layout.

## ✨ Project Overview

This project is designed to help beginners practice:

- 🏗️ Building a basic webpage using HTML
- 🎨 Styling sections with CSS
- 🌐 Creating a beautiful landing page layout
- 💡 Adding simple visual enhancements like hover effects and spacing
- 🧩 Structuring content for a real-world website

The page includes a welcoming hero section, room options, a booking call-to-action, and a footer with contact details.

## 🌟 Features

- 🏙️ Elegant homepage hero section
- 🛏️ Hotel room showcase cards
- 🧼 Clean and modern styling
- 📱 Responsive layout for different screen sizes
- 📅 Booking section with a clear call-to-action
- 📞 Simple contact information in the footer
- 👩‍💻 Beginner-friendly structure and easy-to-read code

## 🛠️ Technologies Used

- HTML5
- CSS3

## ▶️ How to Run the Project

### Option 1: Open directly in the browser
1. Download or clone the project.
2. Open the `index.html` file in your browser.
3. You should see the hotel homepage.

### Option 2: Use a local preview extension
If you are using VS Code:
1. Open the project folder in VS Code.
2. Install a Live Preview or Live Server extension.
3. Open `index.html` and start the preview.
